# keiba — JRA historical data for Benter-style research

2026年秋華賞を対象に、ビル・ベンターの研究手順に沿って独立能力モデルの学習データを用意するプロジェクト。

## 使い方

1. GitHubの **Actions** タブを開く。
2. **JRA Historical Data Collection** を選択する。
3. **Run workflow** を押す。
4. 実行結果の **Artifacts / jra-historical-training-data** から成果物を取得する。

収集対象は2019〜2025年のJRA全10競馬場。公開CSVをダウンロードし、全出走馬の結果・レース情報を統合し、発走前の過去記録だけを使った学習・検証用CSVを生成する。学習用データが2,000レースを満たさなければジョブを失敗扱いにする。

## 重要

- **収集成功とモデル完成は別**。現時点で勝率モデル、ベンター式の市場統合、馬券の期待値推定は未実行。
- 2026年秋華賞の17頭・110走の調査データは前回の別ZIPに保存済み。このリポジトリの収集ジョブへはまだ移植していない。
- 出典: https://github.com/keibamar/keiba_ai_ver2.0 （過去の公開レース結果CSV）。このリポジトリに元データはコミットしない。
- 第三者データの権利・利用規約は確認が必要。現在の本リポジトリは公開設定。Artifactsも公開状態に応じて閲覧され得る。
- 公開CSVの「単勝」は**確定オッズ**であり、発走15分前のオッズではない。事前能力モデルの特徴量に使わない。
- 同日他レースも含め、その日の結果を予測時点の過去情報として使わない。
- ソースがすべて取得できなくても2000レース以上になり得るので、レース件数だけで完全性を証明しない。必ずauditを確認する。
